# Models Directory

The `models/` directory holds the data models and schemas used by the application. These models define the structure of the data and are typically used with an ORM (Object-Relational Mapping) library like SQLAlchemy.

## **Contents**

- **`__init__.py`**: Initializes the `models` package and can be used to import all models for easier access.
- **`openai.py`**: Contains all models required for OpenAI API request/respones.

## **Purpose**

- Defines database schemas and ORM models.
- Centralizes data structure definitions for consistency across the application.
- Facilitates interactions with the database by providing model classes.
